# 🛒 Brazilian E-Commerce Analytics Dashboard

## 📌 Project Overview

The **Brazilian E-Commerce Analytics Dashboard** is a Business Intelligence web application developed using **Python, Flask, Pandas, Matplotlib, Seaborn, HTML, CSS, and Bootstrap 5**.

The dashboard analyzes the Brazilian Olist E-Commerce dataset and presents meaningful business insights through KPIs, interactive reports, tables, and visualizations.

This project demonstrates Data Cleaning, Feature Engineering, Exploratory Data Analysis (EDA), Business Analytics, and Dashboard Development.

---

# 🎯 Objectives

- Analyze Brazilian E-Commerce sales data.
- Build an interactive analytics dashboard.
- Generate business insights using KPIs.
- Visualize sales trends and customer behavior.
- Evaluate product, seller, payment, and delivery performance.
